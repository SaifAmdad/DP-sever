# Dubai Properties

## Installation

Before installing, ensure you have [Node.js](https://nodejs.org/) installed (Node.js 22.17.0 or higher is often required).

1.  **Clone the repository** (if applicable):
    ```bash
    git clone https://github.com/SaifAmdad/DP-sever
    cd DP-sever
    ```
2.  **Install dependencies**:

    ```bash
    npm install
    ```

    If it's a new project, you might need to create a `package.json` file first using `npm init`.

3.  **create a .env file**
    provide values what's mentioned in secret file.

## Usage

CRUD on users and their contributions.

### Command Line to run server

```bash
npm start
```
